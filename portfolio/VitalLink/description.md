# VitalLink

VitalLink is a comprehensive full-stack healthcare application designed to monitor patient vitals and track regional disease statistics across various medical institutions.

## Features Built
- **Patient Monitoring**: Track real-time patient vitals including BPM, Temperature, SpO2, and RR Interval, along with geographic location data.
- **Institutional Authentication**: Secure login and management for healthcare institutions, including password hashing and location tracking.
- **Disease Reporting**: Allows institutions to log and track the frequency of various diseases over time.
- **Modern Tech Stack**: Built with a FastAPI backend, utilizing SQLAlchemy for database ORM, and a React frontend powered by Vite.

## Technologies Used
- Python (FastAPI, SQLAlchemy)
- JavaScript / React (Vite)
- SQLite Database
- Docker and Docker Compose for containerized orchestration
